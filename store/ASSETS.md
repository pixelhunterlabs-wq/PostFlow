# Google Play Store Asset Plan — Kalori Takip

## Required / primary assets

- App icon: 512 x 512 PNG, no rounded-corner mask baked in.
- Feature graphic: 1024 x 500 PNG or JPEG.
- Phone screenshots: portrait 1080 x 1920 recommended for a consistent set.

## Screenshot set

1. Dashboard — daily calories, remaining calories, macros.
2. Add food — manual food entry.
3. Barcode — barcode scan / Open Food Facts lookup.
4. Weekly progress — last 7 days calorie bars.
5. Monthly summary — current month total + daily average.
6. Weight history — recent weight records.

## Visual direction

- Product name: Kalori Takip
- Style: clean, modern, health/fitness utility; not clinical.
- Primary brand direction: fresh green on an off-white background.
- Avoid medical claims, diagnosis language, guaranteed weight-loss claims, or before/after body imagery.
- Screenshots should show realistic sample data only; never use real user account data.

## Feature graphic copy

Primary option:

**Kalorini Takip Et. İlerlemeni Gör.**

Supporting line:

Yemek, makro ve kilo takibi tek uygulamada.

## Play listing consistency

Store screenshots and feature graphic must match features that are actually available in the submitted build. Keep barcode scanning, weekly/monthly history and weight tracking visible because these are implemented in V1.
