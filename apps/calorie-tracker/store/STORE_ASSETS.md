# Kalori Takip — Store Asset Plan

## Required Google Play assets

### App icon
- Final export: 512 × 512 px PNG
- No transparency for the Play listing export
- Keep the in-app adaptive launcher icon visually consistent with the Play icon
- Avoid tiny text; the calorie/food identity should be recognizable at small size

### Feature graphic
- 1024 × 500 px
- Main message: calorie + macro + weight tracking in one place
- Suggested layout: left = app identity, center/right = clean dashboard / food / barcode motifs
- Keep copy short; no medical-treatment promises

### Phone screenshots
Recommended portrait set:
1. Today dashboard — calorie target, remaining calories, macros
2. Food logging — grams, calories, protein/carbs/fat
3. Barcode lookup — scan product and auto-fill nutrition
4. 7-day / monthly progress — history and averages
5. Weight tracking — weight history
6. Account/privacy — cloud sync + account/data deletion

Suggested marketing captions:
- “Günlük kalorini tek ekranda takip et”
- “Protein, karbonhidrat ve yağ hedeflerini gör”
- “Barkodu tara, besin değerlerini hızlıca ekle”
- “7 günlük ve aylık ilerlemeni takip et”
- “Kilo geçmişini hesabınla senkronize et”
- “Verilerin üzerinde kontrol sende”

## Visual direction
- Modern, clean health/fitness UI
- Bright background with strong readability
- Use the same visual language as the launcher icon
- Avoid before/after body transformations, unrealistic weight-loss claims, or diagnostic/medical imagery
- Screenshots must reflect real release-build UI; mockups can frame real screenshots but should not misrepresent functionality
